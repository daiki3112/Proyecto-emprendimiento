# \# 🚀 Mi Emprendimiento Digital

# 

# Bienvenido al repositorio oficial del proyecto \*\*Mi Emprendimiento Digital\*\*, desarrollado como parte del programa Jóvenes CreaTivos.

# 

# Una aplicación web funcional que convierte una idea de negocio en una experiencia digital completa, interactiva y desplegada en internet.

# 

# \---

# 

# \## 🛠️ Características Principales

# 

# \* \*\*Landing / Inicio:\*\* Presentación de marca, banner hero y barra de navegación responsive con indicador activo de sección.

# \* \*\*Catálogo de Servicios:\*\* Tarjetas de productos/servicios con insignias, precios y modal emergente de confirmación interactiva.

# \* \*\*Asistente Virtual con IA:\*\* Chatbot interactivo integrado para orientación de clientes y recomendación de planes en tiempo real.

# \* \*\*Formulario de Contacto Real:\*\* Captura de mensajes y validación de campos.

# \* \*\*Panel de Administración:\*\* Módulo de inicio de sesión (\*Login\*) con dashboard de monitoreo de estado de servidor y latencia (\*ping\*) en tiempo real.

# \* \*\*Pie de Página (Footer):\*\* Enlaces directos de navegación y derechos de autor.

# 

# \---

# 

# \## 💻 Tecnologías Utilizadas

# 

# \* \*\*HTML5:\*\* Estructura semántica de la aplicación.

# \* \*\*CSS3:\*\* Diseños modernos, animaciones, variables y Media Queries para adaptabilidad móvil (Responsive Design).

# \* \*\*JavaScript (ES6):\*\* Lógica del chatbot de IA, manejo de modales, efectos de scroll y monitoreo del servidor.

# \* \*\*Git \& GitHub:\*\* Control de versiones con historial de commits y despliegue continuo.
